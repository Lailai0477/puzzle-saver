# Puzzle Saver

`puzz.link` など、pzpr.js を使うページの解答途中をブラウザ内に保存・復元する Chrome 拡張です。全ページで共通の10個の保存スロットを使います。

## 使い方

1. Chrome の `chrome://extensions` を開き、「デベロッパー モード」を有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」から、このフォルダを選びます。
3. 対象のパズルを開き、拡張機能の Puzzle Saver を押して「現在の進捗を保存」を選びます。
4. 空きスロットの「保存」、または既存スロットの「上書き保存」を選びます。保存時のURLも一緒に記録されます。
5. 「ロードして解く」を選ぶと、そのURLを開いて保存時点の途中経過を自動復元します。

保存には pzpr の `getFileData(FILE_PZPR, {history: true})` を使います。これは SVG の見た目だけではなく、問題・入力済みの解答・操作履歴を含む pzpr の標準形式です。
